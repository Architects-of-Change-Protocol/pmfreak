# Contributing to PMFreak

PMFreak is a private proprietary repository. Unsolicited external contributions are not accepted. Any contribution requires prior authorization from OnChainFest LLC or its designated repository owner.

Contributors must have the right to provide their work, must not copy confidential third-party code, must not include code from prior employers without authorization, and must not add secrets, customer data, personal data, or assets without documented provenance. New dependencies require license and supply-chain review before merge.

AI-assisted changes remain the responsibility of the human contributor. The contributor must review accuracy, security, origin, similarity concerns, and compatibility with repository policies. Depending on business context, contributions may require written agreement, IP assignment, or CLA as determined by the company. This document does not itself create an IP assignment contract.

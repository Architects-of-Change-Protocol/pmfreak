# Release IP Gate

Before any controlled commercial release, the release approver must verify: updated inventory and SBOM, no blocked licenses without complete approved exception evidence, review-required license disposition, asset provenance, ownership evidence, security checks, changelog, artifact manifest, absence of secrets/customer data, third-party notices where applicable, artifact classification, and commercial/legal terms review.

Existing publication paths observed in repository scope include Changesets scripts and restricted AOC package publish workflows. They must not be used to publish the PMFreak product source package and require release approval before use.

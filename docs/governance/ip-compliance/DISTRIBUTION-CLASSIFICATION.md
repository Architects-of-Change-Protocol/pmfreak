# Distribution Classification

| Material | Classification | Distribution posture |
| --- | --- | --- |
| Source repository | Confidential / Proprietary | Internal authorized access only. |
| Production artifacts | Restricted | Release only through approved commercial release gate. |
| Public website assets | Public-facing as deployed; source assets require provenance | Do not assume redistribution rights beyond intended product use. |
| Documentation | Internal, Customer-facing, or Public by document owner decision | Classify before external sharing. |
| Dependency notices | Redistributable as required | Preserve third-party license terms and notices. |
| Test fixtures | Internal | Synthetic only; no customer data. |
| Demo data | Synthetic only | No real customer or personal data. |
| Customer data | Prohibited in repository | Remove from future commits; history remediation requires separate review. |
| Secrets | Prohibited in repository | Store only placeholders in examples. |

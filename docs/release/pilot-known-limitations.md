# Known Limitations — Closed Free Pilot (Pilot Gate Sprint 01)

Audience: the founder (for partner conversations) and design partners who
ask "what should we NOT expect?". Honesty here is a feature: nothing below
is hidden in the product — deterministic surfaces are labeled, placeholder
data is labeled, and curated-out modules are invisible.

## What the AI is — and is not

- **Real AI**: the copilot conversation (`/copilot` surface) runs real LLM
  inference with guardrails, daily request/cost ceilings, and usage
  accounting. It requires the pilot deployment to have a working
  `OPENAI_API_KEY`; there is no canned fallback — if the provider is down,
  copilot returns an error.
- **Not AI (by design, disclosed in-product)**: the Command Center chat is
  a deterministic, rule-based assistant over your project data (~10
  intents); the First Insight project brief is generated by deterministic
  rules from your onboarding answers; the post-onboarding "setting up your
  workspace" screen is a fixed-duration setup animation.
- **No autonomous agents**: nothing in the pilot takes external actions
  (no emails sent by agents, no tickets created, no side effects). The
  agent-execution machinery visible in the codebase is inert scaffolding
  (see `scaffolding-register.md`) and is not part of the pilot surface.

## Dashboard metrics

The portfolio snapshot on `/dashboard` currently shows **placeholder
values** labeled "not yet connected to workspace data" — real per-workspace
portfolio aggregation is roadmap work. Project-level views (tasks, critical
path, briefs, follow-ups) are real and workspace-derived.

## Data & operations

- **Export**: no self-service full-workspace export yet; the operator runs
  a SQL export on request (pilot commitment, RR-EXPORT).
- **Deletion**: no self-service account deletion; handled by the operator
  on request during the pilot.
- **Backups**: logical backup/restore drill rehearsed with evidence;
  hosted PITR confirmation is a pre-pilot operator step (RR-BACKUP).
- **Monitoring**: log/audit-table based with a manual daily cadence — no
  external alerting platform yet (RR-MONITOR).
- **Support**: founder-led, direct channel; no support console.

## Auth & access

- Email/password only (no OAuth/social login, no MFA yet — planned before
  public launch stages).
- Workspace invite links are returned to the inviter for out-of-band
  delivery (not emailed automatically).

## Not in the pilot (deliberately)

Governance approvals/policies/audit UI, trust/attestation surfaces,
PM Registry/Performance/Capacity pages, marketplace/API/SSO/SCIM — either
curated out for the pilot (`pilot-capability-set.md`) or not built.
Locally-implemented trust/claims code is never presented as canonical AOC.

## Legal

No published ToS/Privacy yet; the closed free pilot runs on a direct,
signed pilot agreement per partner (see `pilot-agreement-readiness.md`).
Published legal minimum is required before any paid stage.
